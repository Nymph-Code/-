# 泰坦尼克号生存预测(PyTorch)

根据乘客的个人信息,预测他是否在泰坦尼克号事故中幸存。这是一个二分类任务:

- `1` 表示幸存(Survived)
- `0` 表示遇难(Deceased)

模型是自己用 PyTorch 的 `torch.nn.Module` 搭的全连接神经网络,没有用现成的机器学习分类器。

## 运行方法

先装依赖:

```
pip install -r src/requirements.txt
```

然后训练 + 评估 + 演示预测,一条命令就够了:

```
python src/main.py
```

跑完之后:

- 终端会打印每一轮的损失和准确率,以及最终的测试集准确率
- `save/` 里会生成模型参数和预处理参数
- `docs/` 里会生成两张曲线图

## 单独预测新乘客

`main.py` 跑完之后,可以单独运行预测脚本,自己输入一名乘客的信息:

```
python src/predict.py
```

它会先自动测一个示例乘客,然后让你手动输入:

```
性别 (male/female): female
年龄 (比如 22): 30
舱位等级 (1/2/3): 1
同行的兄弟姐妹或配偶数 SibSp (没有填 0): 0
同行的父母或子女数 Parch (没有填 0): 0
票价 Fare (比如 7.25): 100
登船港口 (C/Q/S): C
姓名(可以留空,留空就按性别年龄猜称谓):
```

输出比如 `预测结果 = 1 (1=幸存, 0=遇难)   生存概率 = 98.48%`。

## 主要配置

| 项目 | 取值 |
| --- | --- |
| 随机种子 | `SEED = 42` |
| 数据划分 | 训练集 : 测试集 = 8 : 2(712 / 179 条) |
| 模型结构 | 10 → 32 → 16 → 1,ReLU,Dropout 0.2 |
| 损失函数 | `nn.BCELoss` |
| 优化器 | Adam,lr = 0.001,weight_decay = 1e-4 |
| 训练轮次 | 150 |
| 批大小 | 32 |
